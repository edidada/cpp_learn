针对你提到的编程语言，搜索到的带习题的书籍主要集中在 C、C++、Rust、Go、C# 和 Python。Zig 语言因为相对较新，搜索到的两本英文书虽然都声称包含练习，但作者背景和出版社信息比较模糊，权威性一般，这里也一并列出供你参考。

### 各语言带习题的书籍

C 语言
*   《C语言实用编程550例》：包含400个实例和150个实练题目，覆盖基础到算法，配套视频和在线刷题。
*   《C语言程序设计教程（第6版）》：分为基础、提高、实验篇，含17个实践性实验，各章配有丰富习题，适合教学与自学。

C++
*   《C++程序设计基础实践教程》：专为实践设计，包含程序调试题、完善程序题和编程题，以及多套模拟试卷。
*   《计算机与程序设计基础:C++版》：国家级一流本科课程配套教材，每个知识点都有实现代码和实例，每章附有习题。

Rust
*   《The Rust Programming Language Workbook》：受 Rustlings 项目启发，提供按主题组织的短小练习，包含刻意“破坏”的代码供读者修复，并附有提示和答案。
*   《Rust: The Practical Guide》：从基础到高级主题，每章末尾设有实践问题，用于强化所学概念。

Go
*   《Go 學習手冊 第二版》：在讲解惯用 Go 程式写法的同时，新增了章后练习题，便于吸收和内化知识。
*   《Exercise Go プログラマ脳を鍛える至高の問題集》：收录了25道关于 nil、闭包、切片等特性的难题，旨在通过解题加深对 Go 的理解。

C#
*   《C#实用教程（第4版）》：教材包含专门的“C#习题”部分，涵盖选择题、编程题等，并有实训和综合应用案例。

Python
*   《Python题库精选》：题量巨大，包含3634道客观题和832道编程题，覆盖基础到数据分析、网络编程等领域。
*   《Python语言程序设计(基础篇)》：经典教材，包含大量不同难度的练习题，指导读者在实践中掌握编程技巧。

Zig（权威性待确认）
*   《Zig by Example》：声称包含大量实践示例和练习，帮助读者构建实际应用。
*   《Zig Programming for Developers》：声称包含动手练习，让读者实践所学内容。

### 💡 一个跨语言的补充选择
如果你更看重算法与数据结构的练习，可以关注开源的 《Hello 算法》。它的特色是提供动画图解和可一键运行的代码，并且同时支持你提到的所有语言（C、C++、Rust、Go、C#、Python、Zig），非常适合用来对照学习不同语言的实现方式。
